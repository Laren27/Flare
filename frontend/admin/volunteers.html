Future Scope
Not built. Certificate upload and admin approval need a certificate_path column that does not exist, so the rows below are sample data and the buttons are disabled. Manual approval is the deliberate design (ADR-006) — automated document verification is a project of its own.

What is actually enforced

Verification is a real column on the volunteer record and the dispatch engine does honour it — an unverified volunteer is rejected during candidate evaluation with reason unverified, and that rejection is logged like any other (ADR-014, ADR-021). What is missing is the interface for changing that flag: it is set by sim/seed.py or by hand, not by an admin approving a document. The queue above shows the shape the feature would take.
